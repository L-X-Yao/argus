# 飞行测试流程

> English: [FLIGHT_TEST.md](FLIGHT_TEST.md)

Argus 已在台架和 SITL 上测试，尚未飞行。这是 ArduCopter 的保守首飞流程。它是起点：遵守飞行所在地的法律和空域规则，以及飞机负责人的程序。

## 角色

- **机长**：手持遥控器，随时可以接管。
- **地面站操作员**：操作 Argus，并朗读遥测。
- **观察员**：观察空域、人员和飞机；不看屏幕。

首飞时一个人不能兼任所有角色。解锁前先约定中止口令。

## 到场前

- 检查参数、失效保护、罗盘、加速度计和遥控校准。
- 解锁前确认三维 GPS 定位、健康的 EKF 和清晰的 home 点。
- 给电池充电并设计时器；不要计划用最后 30%。
- 围栏和计划任务保持在合法飞行范围内。
- 一次只用一个地面站。关闭其他地面站和 MAVLink 客户端。
- 只在室外、机长就位、区域清空时装桨。

## 本版本的放行检查（v3.16.8）

在本次发布后的首次飞行前，把飞机放在台架上：

1. 设置页显示 **3.16.8**。参数包是 `data-v2026.11.6`。
2. 读取全部参数。测试用 Copter 约 1,396 个名字；面板应显示飞行参数的中文说明，而不是 `EN` 回退。
3. 检查两个 4.7 改名通过别名解析：`SR0_ADSB` 和 `CAM_RC_TYPE` 的说明应与 `MAV1_ADSB` 和 `CAM1_RC_TYPE` 相同。
4. 断开网络再打开参数面板：内置说明仍应出现。
5. 校准：从面板运行陀螺仪校准。它必须在飞控应答后自行结束，没有消息也没有取消；随后气压计运行以 `Barometer calibration complete`（气压计校准完成）结束。
6. 日志：在尝试“擦除全部”前先列出并下载一份日志。擦除全部不可恢复，不属于首飞内容。

## 台架检查，拆桨

1. 在 Argus 中连接飞控。WebSerial 和后端串口链路都可用于本步。
2. 看状态栏和预飞检查：电池电压、模式、未解锁、无 prearm 错误。
3. 用滑块解锁。应看到解锁应答和阶段变化；不要把电机响应当作飞行行为的测试。
4. 切换一个模式再切回。上锁。
5. 如果上锁被拒绝，用滑块强制上锁。到场前查清飞控为什么拒绝。
6. 打开事件日志和飞行日志。会话中应包含解锁、模式切换和上锁事件。

台架解锁不是飞行。它不会改变 [VERIFICATION.md](VERIFICATION.md) 中 `Real flight` 一行的状态。

## 首次外场飞行

在留有返航和降落空间、远离人员和财产的场地飞行。机长全程手持遥控器。

1. 连接，等待三维定位和健康 EKF，读取电池电压。
2. 把“起飞”旁的高度设为 10 m，默认是 30 m。解锁。起飞并悬停。用 HUD 和观察员确认高度与位置。
3. 返航。确认爬升到配置的返航高度、返航、降落并上锁。
4. 在地面再次解锁。上传三个航点的短任务，然后启动。观察航点计数推进。
5. 在第二个航点返航。确认返航、降落和上锁。
6. 检查飞行总结，然后清除任务。

首次飞行不要同时做新校准、新固件、新机架或长任务。一次只改一件事。

## 中止

出现任何 prearm 拒绝、EKF 失效保护、电池压降、振荡、异常模式或高度、GPS 丢失、围栏越界、区域内出现飞机或人员、链路无法恢复时，中止飞行。

- 机长先接管；地面站操作员报告飞机状态。
- 视情况用降落或返航。只在地面上锁。
- 不要用地面站追飞机。遥控链路是首要控制。
- 如果地面站链路丢失，WebSerial 从 USB 按钮重连；后端链路自行重连。机长不等任何一个。

## 记录

记录日期、机型、固件版本、Argus 版本、链路类型、风、电池、飞行时间、日志文件名和任何异常。板名、序列号和地点不要写进公开仓库。

## 飞行后

- 再次飞行前先下载日志。
- 更新 [VERIFICATION.md](VERIFICATION.md)：`Real flight` 一行填日期和飞了什么；命令行在 Evidence 中填日期。
- 只有飞行确实发生后，才更新 `README.md` 与 `README.zh.md` 的状态措辞。一次短飞成功不能证明所有任务都安全。
